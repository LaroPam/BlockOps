# Совместная игра в открытом для сети мире Minecraft Java

BlockOps может направить соединение к миру, запущенному в самом Minecraft. Хост
открывает свой Minecraft через обычный лаунчер: его моды и конфиги остаются в клиенте,
BlockOps их не изменяет. Хост играет в уже открытом мире на том же компьютере.

1. Хост входит в одиночный мир и выбирает в Minecraft «Открыть для сети». В зависимости
   от версии игры меню и параметры могут отличаться.
2. В экспериментальном моде Fabric 1.21.1 хост вводит в мире `/blockops`, копирует локальный
   код и в BlockOps выбирает «Определить порт через мод». Приложение получает порт из
   встроенного сервера Minecraft. Без мода порт можно взять из сообщения игры и указать
   вручную. Код одноразовый и предназначен только для этого компьютера.
3. Хост подготавливает соединение и создаёт одноразовый код для друга. Подготовка
   соединения сама по себе не подтверждает, что Minecraft доступен; это выяснится при
   подключении.
4. Друг запускает BlockOps, выбирает «Присоединиться» и вводит код. Затем он открывает
   Minecraft Java и подключается к адресу `127.0.0.1:…`, который покажет BlockOps на его
   компьютере. Этот локальный порт может отличаться от порта мира хоста.
5. Когда игра закончена, хост отключает соединение в BlockOps. Автоматического определения
   закрытия мира и остановки туннеля пока нет; повторное открытие мира может дать новый порт.

Для игры через интернет нужны доступные координатор и relay: оба игрока указывают адрес
одного координатора, а хост — адрес relay. Настройки находятся в дополнительных настройках.
Доступной публичной инфраструктуры BlockOps пока нет. Текущая модель использует отдельный
одноразовый код для каждого друга, а не постоянную комнату с именем и паролем.

Открытие мира Minecraft для сети также может сделать его доступным в локальной сети хоста
согласно настройкам Minecraft и Windows. Туннель BlockOps направлен на выбранный порт
локального компьютера, но не проверяет протокол или то, какому приложению принадлежит порт.
При закрытии мира остановите туннель: тот же порт позднее может занять другая программа.

Совместимость модов, версий и загрузчиков Minecraft зависит от конкретной сборки: многим
модам нужны совместимые версии у обоих игроков. BlockOps пока не синхронизирует моды и не
проверяет их совместимость. Для определения порта через мод пока нужно вручную сопрячь
его с приложением; автоматическое сопряжение и проверка реальной LAN-игры с модами на
двух Windows-компьютерах через интернет остаются следующими этапами.
