# Дизайн BlockOps

Для текущего этапа BlockOps — приложение **для Windows**. Интерфейс должен помогать
игроку создать свой сервер или присоединиться к другу без технических знаний. Не делаем
отдельный desktop-дизайн для Linux и macOS; Linux остаётся средой для разработки и тестов.

При проектировании используем принципы [Hallmark](https://github.com/nutlope/hallmark),
адаптированные к экрану приложения, а не к рекламному сайту:

- На первом экране видны реальные основные действия; подробности раскрываются по мере
  необходимости. Списки, консоль, управление сервером и восстановление остаются рабочими.
- Статусы, счётчики и сообщения основаны на настоящих данных. Если инфраструктура ещё не
  развёрнута, интерфейс прямо сообщает об этом; фиктивных подключений нет.
- Простые формулировки, сдержанный тёмный фон и один основной акцент. Типографика опирается
  на системный шрифт Windows; цвет и шрифт задаются токенами в `style.css`.
- Все управляющие элементы доступны с клавиатуры, имеют видимый фокус и понятные состояния;
  опасное восстановление требует подтверждения. На узком окне текст может переноситься.
- Движение не украшает экран; соблюдаем системную настройку уменьшения анимации.
- Не добавляем декоративные метрики, рекламные баннеры и карточки ради заполнения места.

Сейчас обзор через браузер показывает только интерфейс: управление зависит от Tauri.
Windows-приложение и установщик необходимо дополнительно проверить на Windows.
