# Итерация 4 — подготовка Windows и HTTPS-пилота

- Валидация `server.properties` теперь отклоняет альтернативные разделители Java Properties,

  сохранёнными Minecraft properties повторно запущен и штатно остановлен.
- Гость резервирует loopback TCP listener до погашения одноразового кода; занятый или

  10-секундное окно подтверждения. Добавлены тесты обоих случаев.

  отклонён. Системное доверие не менялось. Этот тест не проверяет Caddy или публичный VPS.
- Синтаксис systemd unit templates проверен `systemd-analyze verify` после подстановки
  существующих локальных бинарников. Caddy в среде отсутствует; сам Caddyfile не проверен.
- Windows workflow дополнен сборкой NSIS, тихой установкой и удалением и сохранением

- Публичный relay, NAT/CGNAT и вход лицензированного игрока всё ещё не проверены.
- Итоговый прогон: 29 тестов, Clippy (`-D warnings`), форматирование, Rust build и

# Автоматическое сопряжение с модом

- Мост мода больше не принимает секрет в заголовке: каждый запрос подписан HMAC-SHA256 с новым
  случайным значением, а успешный ответ мод подтверждает своей подписью. Rust-клиент отклоняет
  ответ без подписи, с подписью другого запроса или с подменённым портом.
- На Windows мод публикует одноразовый мост в файле, доступном только текущему пользователю,
  заменяет использованный или истекающий мост, удаляет файл при выходе и старые файлы при запуске.
  BlockOps находит открытый мир и запускает вход гостя без кода; код вручную остался запасным путём.
- **69 Rust-тестов**, Clippy (`-D warnings`), форматирование, Rust build, `smoke.py`,
  `coordination_smoke.py`, `https_pilot_smoke.py`, сборка интерфейса и UI-тест с mock Tauri прошли.
- Сборка мода Gradle прошла на Linux: проверки моста, публикации и очистки устаревших файлов, а также
  Rust↔Java проверки входа, порта мира и наблюдения за миром по новому протоколу.
- Windows-проверка мода (создание файла через WinAPI из JNA, приём Rust-читателем, отказ для
  наследуемых прав, полная цепочка обнаружения) добавлена в Windows CI, но здесь не запускалась:
  Windows в среде нет. Windows-код Rust проверен `cargo clippy --target x86_64-pc-windows-msvc`
  без запуска. Tauri type-check и Clippy выполнены с синтетическим pkg-config, без линковки.
- Настоящий Minecraft, лаунчеры с виртуализацией файловой системы (например, из Microsoft Store),
  Windows GUI и игра двух игроков не проверены.

# Автоматическое подключение

- Мод сообщает в приватном дескрипторе (формат версии 2), чем занята игра: мир открыт для сети,
  главное меню или другое. Смена состояния перезаписывает файл без расхода моста.
- Хост: BlockOps само замечает открытый для сети мир, «Пригласить друга» одним нажатием готовит
  соединение и первый код, код копируется кнопкой. Гость: после ввода кода Minecraft подключается
  сам, когда оказывается в главном меню, и только один раз за соединение.
- Тест Windows-прав из итерации обнаружения, падавший в CI с момента добавления, создаёт
  приватный файл так же, как мод: `icacls /inheritance:r` не удаляет явные права, которые раннер
  GitHub выдаёт новому файлу. Windows-сборка мода с проверкой записи дескриптора уже прошла в CI.
- **69 Rust-тестов**, Clippy, форматирование, Rust build, три smoke-скрипта, сборка интерфейса,
  UI-тест (включая автоматические сценарии хоста и гостя с mock Tauri) и сборка мода с
  Rust↔Java проверками прошли. Tauri проверен с синтетическим pkg-config, без линковки.
- Настоящий Minecraft, Windows GUI, лаунчеры с виртуализацией файловой системы и игра двух
  игроков по-прежнему не проверены.

# Доводка подключения

- Адреса сервиса координации и relay сохраняются между запусками; кнопка возвращает локальные
  настройки. Ошибки координатора (недоступен, не HTTPS, некорректный адрес) показываются
  понятными подсказками, в том числе в списке кодов.
- Код приглашения принимается без учёта регистра, с пробелами вместо дефисов и с O, I, L вместо
  0, 1, 1. Проверено модульным тестом и полным циклом погашения в `tests/flow.rs`.
- UI-тест проверяет сохранение адресов после перезагрузки, сброс и текст ошибки недоступного
  координатора. **70 Rust-тестов**, Clippy, форматирование, три smoke-скрипта, сборка интерфейса
  и Tauri Clippy с синтетическим pkg-config прошли.
