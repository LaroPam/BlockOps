  `coordination_smoke.py`, `https_pilot_smoke.py`, сборка интерфейса и UI-тест с mock Tauri прошли.
- Сборка мода Gradle прошла на Linux: проверки моста, публикации и очистки устаревших файлов, а также
  Rust↔Java проверки входа, порта мира и наблюдения за миром по новому протоколу.

# Приглашение одним сообщением

- «Пригласить друга» копирует готовое сообщение с кодом и сроком действия; кнопка у кода копирует

# Режим без сервера

- Модуль PAKE: совпадающий код даёт обеим сторонам одну capability, неверный код ничего не
  выдаёт и засчитывается как попытка, обмен не переносится на другой PeerId, формат и ключ
  встречи кода. Интеграционный тест с локальным DHT-сервером и relay с лимитами публичных relay:
  встреча, PAKE, пробивание прямого пути, 512 КиБ данных игры, отказ повторного кода, отказ
  неизвестного кода, закрытие игры при отзыве. Тест стабилен в 5 прогонах подряд.
- Приложение: способ соединения в настройках (по умолчанию без сервера), код из четырёх групп
  выбирает режим у гостя, автовход Minecraft ждёт готового маршрута. UI-тесты покрывают выбор
  способа, вставку приглашения нового формата и ожидание маршрута.
- **83 Rust-теста**, Clippy, форматирование, smoke-скрипты, сборка интерфейса и Tauri Clippy с
  синтетическим pkg-config прошли.
- Настоящая публичная сеть IPFS, пробивание реальных NAT, брандмауэр Windows и игра двух

# Мир находится в любой версии

- BlockOps слушает объявления «Открыть для сети» (224.0.2.60:4445), принимает только объявления
  с адресов своего компьютера, читает версию сервера статус-запросом и отслеживает мир, пока
  объявления продолжаются. Если мод установлен, порт берётся у него.
- Модульные тесты разбора объявлений и проверки локальных адресов; интеграционный тест через
  настоящий multicast с поддельным сервером Minecraft: мир найден с названием и версией 1.20.1,
  а после прекращения объявлений считается закрытым. UI-тест сценария без мода.
- В настоящих версиях Minecraft и в Windows (брандмауэр, несколько сетевых адаптеров) не
  проверено.
- Гость: постоянный адрес 127.0.0.1:25595 с запасным случайным, сервер «BlockOps — мир друга» в
  `servers.dat` всех сборок одной кнопкой. Тесты NBT: побайтовый круговой разбор всех типов тегов,
  отказ для усечённого и лишнего ввода, запись первой в список с сохранением остальных записей и
  неизвестных тегов, повторный вызов без изменений, создание списка, отказ для битого файла без
  изменений, копия `servers.dat_old`. UI-тест кнопки и предупреждения о занятом адресе. Чтение
  записанного файла настоящим Minecraft не проверено.

- Ядро мода (мост, протокол, публикация, приватный файл Windows) вынесено в `mods/common` и
  компилируется в каждую сборку; у каждой сборки свой тонкий слой интеграции. Собраны и
  проверены по содержимому JAR: Fabric 1.21.1 (с проверками ядра), Fabric 1.20.1 (Java 17,
  вложенные модули Fabric API 1.20.1), NeoForge 1.21.1, Forge 1.20.1 (Java 17, имена для
  настоящей игры после reobf). Сигнатуры API 1.20.1 сверены `javap` с настоящими JAR игры.
- Каждый JAR называет свою цель в `blockops.json`; установщик выбирает нужный JAR по
  загрузчику и версии сборки и узнаёт свои старые JAR. Тесты: выбор JAR для четырёх сборок,
  обновление старого JAR без метки, отказ при общей папке с другим загрузчиком.
- CI собирает все четыре цели и кладёт их в установщик; smoke-тест проверяет, что все четыре
  JAR есть в установленном приложении.
- Ни одна сборка мода не проверена в настоящем Minecraft.

# Свои серверы на популярных версиях

- Список версий: 26.3, 1.21.11, 1.21.4, 1.21.1, 1.20.4, 1.20.1, 1.19.2, 1.18.2, 1.16.5, 1.12.2.
  Номер Java у каждой сверен с официальными метаданными Mojang (25, 21, 21, 21, 17, 17, 17, 17,
  8, 8); при установке метаданные проверяются снова.
- Через новый код из Adoptium скачаны и проверены по SHA-256 Temurin JRE 8u504 и 25.0.5 для
  Linux; распаковка, проверка `java -version` и повторное использование установленной среды
  прошли. Разбор версии Java проверен на строках 1.8.0, 17, 21, 25 и 25.0.5.
- Журнал для 1.12.2 и 1.16.5 проверен с настоящим Log4j 2.8.1: строки `${jndi:ldap://…}` и
  `${sys:java.version}` попадают в консоль и `logs/latest.log` как есть, а в контрольном запуске
  с обычным шаблоном Log4j пытается подключиться по LDAP. Строки «Done (…)! For help, type»
  выводятся в прежнем виде, поэтому определение готовности сервера не меняется.
- Тесты `server.properties` для каждой версии: числовые режимы 1.12.2, отсутствие
  `enforce-secure-profile` до 1.19, `online-mode=true` и `server-ip=127.0.0.1` везде. UI-тест
  создания сервера 1.12.2 с подсказкой о Java 8.
- Ни одна новая версия сервера не запускалась: это требует принятия EULA пользователем.

# Готовность к игре

- Чтение списка серверов без записи (`has_entry`): находит добавленный и чужой сервер, не создаёт
  файл, если его нет, и сообщает об ошибке для битого файла. Папки игры для проверки и для
  добавления сервера собираются одной функцией.
- UI-тест панели: найдены две сборки; у хозяина пункт мира меняется на «Найден «Steve - World»,
  Minecraft 1.20.1» без нажатий, когда мир открыт для сети; мод предлагается только для подходящей
  сборки и ставится только после подтверждения; у гостя сервер добавляется одной кнопкой, после
  чего панель сообщает «Всё готово к игре». Внешний вид проверен на ширине 1200 и 420 пикселей.
- На настоящем Windows не проверено.

# Игроки, уведомления и пинг

- Модульные тесты разбора: вход 1.21.1 (с UUID после имени), Forge 1.20.1 (метка FML в адресе),
  1.12.2, перенос (next state 3), запрос состояния и старый пинг 0xFE; недопустимые имена дают
  вход без имени; неверное и слишком длинное начало — «неизвестно», а слишком короткое
  остаётся нерешённым до таймаута. Каждый случай проверен и целиком, и по одному байту.
- Разбор не задерживает данные: первая версия ждала полного пакета, и тесты координации с
  короткими не-Minecraft сообщениями в CI упали по таймауту. Теперь копия начала разбирается
  параллельно с передачей; все тесты рабочего пространства проходят.
- Сквозной тест через настоящий туннель (хост и гость на loopback, эхо-сервер вместо мира):
  запрос состояния проходит без изменений и не добавляет игрока; вход добавляет «Steve», игра
  продолжает идти через туннель, пинг измеряется у гостя и у хоста, после закрытия соединения
  игрок пропадает.
- UI-тест: список «В мире: 2» с пингом и «Друг» для игрока без имени, уведомления о входе и
  выходе исчезают сами при продолжающемся опросе состояния; пинг у гостя.
- Уведомления Windows (плагин уведомлений Tauri, отправка из Rust, когда окно не в фокусе) и
  настоящий Minecraft не проверены.

# Друзья без кода

- Модульные тесты книги друзей: ключ, место встречи, друзья и миры переживают перезапуск; файл
  записывается с правами 0600 (Unix); записи заменяются и забываются, действует предел в
  16 друзей; повреждённый файл не перезаписывается; места встречи разных хостов и коды не
  совпадают.
- Сквозной тест через локальный узел DHT и relay: первый вход по коду передаёт гостю мир
  (хост, возможность, место встречи, название), хост узнаёт друга и ту же возможность; в новом
  сеансе того же хоста друг входит без кода, получает прямое соединение и играет; та же
  возможность с другим ключом отклоняется; «Забыть» обрывает открытое игровое соединение и
  закрывает вход.
- UI-тесты: «Запомнить друга» после входа по коду и «Забыть» у хоста; «Войти» в мир друга у
  гостя с понятной ошибкой, когда мир не найден, и успешным входом со второй попытки.
- В настоящей публичной сети и на Windows не проверено.
