# Проверка предварительной версии BlockOps для Windows

Это тестовая сборка. Она позволяет установить BlockOps и управлять сервером Vanilla,
но интернет-игра требует отдельно развёрнутых и настроенных координатора и relay.

## Установка

1. Откройте [GitHub Actions](https://github.com/LaroPam/BlockOps/actions/workflows/ci.yml)
   и выберите успешно завершённый запуск для ветки `main`.
2. Внизу страницы запуска скачайте артефакт `blockops-windows-nsis` и распакуйте ZIP.
   Для скачивания артефакта может потребоваться вход в GitHub; срок его хранения ограничен.
3. Запустите файл `*-setup.exe` и следуйте инструкциям установщика. Сборка пока не
   подписана цифровым сертификатом: Windows может показать предупреждение о неизвестном
   издателе. Проверяйте, что файл получен из указанного репозитория.
4. Запустите BlockOps. Если Windows попросит установить WebView2 Runtime, установите его
   из официального источника Microsoft.

## Проверка сервера

1. Нажмите «Создать сервер», выберите версию, название и нужные параметры. Прочитайте
   Minecraft EULA и, если принимаете условия, отметьте согласие. BlockOps скачает файлы
   сервера и Java; для этого нужен доступ в интернет и свободное место на диске.
2. После создания нажмите «Запустить» и дождитесь состояния «Работает». Первый запуск
   может занять несколько минут. При ошибке откройте технические подробности и консоль.
3. Остановите сервер кнопкой «Остановить», дождитесь окончания сохранения и запустите
   его снова. Проверьте доступность мира и консоль после повторного запуска.
4. При желании создайте резервную копию остановленного мира. Она хранится на этом же
   компьютере; для защиты от отказа диска нужна отдельная копия на другом носителе.

Автоматическая проверка GitHub собирает установщик, выполняет тихую установку, проверяет
открытие и закрытие окна и удаляет приложение. Она не проверяет действия внутри интерфейса,
запуск реального Minecraft и подключение игроков. Для игры через интернет публичные сервисы BlockOps пока не предоставлены;
тест на двух компьютерах требует развёрнутых сервисов и отдельной проверки.
