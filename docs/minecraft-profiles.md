# Поиск сборок Minecraft

По команде пользователя BlockOps читает `launcher_profiles.json` официального Minecraft
Launcher и связанные JSON-файлы версий в выбранной папке. На Windows пустой путь означает
`%APPDATA%\.minecraft`; путь к другой папке можно ввести вручную. Отображаются название
профиля, его папка игры, обнаруженный загрузчик и версия Minecraft, если она найдена.
Поиск не меняет файлы и не запускает Minecraft.

Загрузчик определяется по координатам библиотек в метаданных версии и её родителей,
а не по имени профиля. Поддержаны признаки Fabric, Forge и NeoForge. Если метаданные
отсутствуют, противоречат друг другу или не относятся к известной схеме, выводится
неопределённый результат. Сборка с пользовательской меткой не считается Vanilla только
из-за отсутствия известной библиотеки. Профили других лаунчеров, например с отдельными
базами и структурами каталогов, пока не распознаются автоматически. Обнаружение не
доказывает совместимость модов, не определяет запущенный профиль и не проверяет, можно
ли безопасно установить мод в папку.

Пользователь может выбрать найденную папку или указать существующую папку сборки
вручную, затем сообщить, установлен ли Fabric, Forge, NeoForge, нет загрузчика или ответ
неизвестен. BlockOps сохраняет этот ответ и путь в собственных данных приложения; выбор
не меняет файлы Minecraft и не является подтверждением совместимости или разрешением на
установку.

## Установка мода BlockOps

Моды BlockOps поставляются вместе с установщиком BlockOps для сборок Fabric 1.21.1,
Fabric 1.20.1, NeoForge 1.21.1 и Forge 1.20.1. В списке найденных сборок у профиля одной из них с
полными метаданными есть кнопка установки, обновления или удаления мода; BlockOps сам выбирает
нужный файл. Файл записывается только после подтверждения. Перед записью BlockOps заново читает
профили лаунчера и проверяет, что из выбранной папки игры запускается поддерживаемая сборка, а
все остальные профили, использующие ту же папку, — та же сборка или Vanilla. Мод требует своей
версии Minecraft, и сборка другой версии или другого загрузчика в той же папке перестала бы
запускаться; в таком случае BlockOps предложит указать сборке отдельную папку игры в Minecraft
Launcher.

Свой мод BlockOps узнаёт по файлу `blockops.json` внутри JAR (у ранних версий — по
идентификатору `blockops` в `fabric.mod.json`), а не по имени файла. Новая версия записывается
под скрытым временным именем, затем старые копии удаляются и файл переименовывается в папке
`mods`; другие файлы сборки не меняются. Если имя файла мода занято файлом, который не удалось
опознать как мод BlockOps, установка отказывает, ничего не меняя. Если файл занят запущенной
игрой, BlockOps просит закрыть Minecraft. Для Fabric отдельно ставить Fabric API не нужно:
нужные модули вложены в мод. Загрузчики (Fabric Loader, Forge, NeoForge) BlockOps не
устанавливает. Сборки других лаунчеров пока не поддерживаются: в них мод можно скопировать
вручную. Без мода BlockOps всё равно находит открытый мир и подключает гостя в любой версии.
